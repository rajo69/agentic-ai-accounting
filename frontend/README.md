# AI Accountant frontend

Next.js 14 app (TypeScript, Tailwind 3.4, Base UI primitives) for the landing page, the review console and the browser-only demo mode under `src/demo/`. See the [project README](../README.md) for the product and architecture, and `npm run dev` to start it on port 3000 with `NEXT_PUBLIC_API_URL` pointing at the backend.
